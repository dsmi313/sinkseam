# sinkseam

Empirical evaluation of whether the **sinker (SI)** and **two-seam fastball
(FT)** represent meaningfully distinct pitch classifications in MLB Statcast
data (2020–2023).

## Research question

Does the SI/FT pitch label predict outcomes (ground ball rate, whiff rate, wOBA
against) above and beyond the movement features themselves (pfx_x, pfx_z,
release_speed)?

## Two-stage analysis

1. **GMM** (`mclust`) on pfx_x (sign-adjusted for handedness), pfx_z, and
   release speed — does the data prefer two natural clusters, and do they
   align with the Statcast labels (ARI)?
2. **Bayesian hierarchical regression** (JAGS via `jagsUI`) with
   pitcher-level random intercepts.  The estimand is `beta_label`: a 95 %
   credible interval that includes zero means the label adds nothing beyond
   movement.

## Running the pipeline

```r
# 1. Pull raw data (requires internet + baseballr).
source("R/01_data_pull.R")

# 2. Clean and engineer features/outcomes.
source("R/02_clean.R")

# 3. Fit GMM, compute ARI, save cluster assignments.
source("R/03_gmm.R")

# 4. Fit Bayesian hierarchical models (JAGS, ~20-60 min depending on hardware).
source("R/04_jags_model.R")

# 5. Render publication figures.
source("R/05_figures.R")

# 6. Compile manuscript.
rmarkdown::render("reports/analysis.Rmd")

# 7. Launch Shiny explorer.
shiny::runApp("app/")
```

## Key conventions

- `pfx_x` sign is **flipped for LHP** so arm-side movement is always positive.
- Features are **standardised** (μ = 0, σ = 1) before GMM and JAGS.
- JAGS uses **precision parameterisation** (τ = 1/σ²), weakly informative
  priors Normal(0, 1) on the logit scale.
- Convergence criterion: Gelman–Rubin **R̂ < 1.1** for all monitored nodes.
- `jagsUI::jags()` is used (not `R2jags`), with `parallel = TRUE`.

## Adjusting parameters

| Parameter | Location | Note |
|---|---|---|
| Year range | `R/01_data_pull.R` line 12 | Change `YEARS <- 2020:2023` |
| Outcome variable | `R/04_jags_model.R` | All three outcomes run by default |
| wOBA weights | `R/02_clean.R` lines 17–24 | Update for different year ranges |
| MCMC settings | `R/04_jags_model.R` `run_model()` | `n_iter`, `n_burnin`, `n_thin` |
